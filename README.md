## 💡 Tentang Proyek
**Smart Laundry** adalah sistem *Digital Twin* berbasis web untuk memantau status operasional mesin cuci secara *real-time* (aktif/standby, estimasi sisa waktu) serta mengontrol tingkat kepadatan pengunjung di area *laundry* koin.
